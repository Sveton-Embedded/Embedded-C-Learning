# Embedded-C-Learning
In this repository, I will explore the fundamental functions needed to write code for microcontrollers.

1. Enums — engine states, error codes, and operating modes.

2. Bitwise operations (&, |, ^, ~, <<, >>) — a crucial topic in embedded systems.

3. Header files (.h) and project modularity — organizing code professionally.

4. const and volatile — critical qualifiers for working with memory and microcontroller registers.

5. Microcontroller registers — practical application of bitwise operations.
